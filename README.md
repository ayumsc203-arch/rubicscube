# 🧊 Solve Rubik Cube with Ayu

> **Solve Any Cube. Master Every Move.**

**Solve Rubik Cube with Ayu** is an interactive Rubik's Cube learning and solving platform designed to help beginners and speedcubers **learn, practice, solve, and improve** their cubing skills.

The platform combines an attractive modern interface with interactive cube tools, learning resources, algorithms, speed training, challenges, and a community-focused experience.

---

## ✨ Features

### 🧠 AI Cube Solver

Enter a cube scramble and get a step-by-step solution designed to help you understand the moves rather than simply showing the answer.

### 📷 Cube Scanner

The platform is designed around an AI-powered cube scanning experience for detecting a scrambled cube and generating a solution.

### 📚 Interactive Learning

Learn cubing progressively through a structured learning path:

* Beginner Foundations
* F2L — First Two Layers
* OLL — Orientation of the Last Layer
* PLL — Permutation of the Last Layer
* Advanced CFOP
* Speedcubing Mastery

### 📐 Algorithm Library

Practice important speedcubing algorithms including:

* F2L
* OLL
* PLL
* ZBLL
* CFOP techniques

### ⏱️ Speed Timer

Practice your solving speed with a dedicated timer and improve your personal records.

### 🧩 Multiple Cube Types

The project includes a cube library featuring:

* 2×2 Pocket Cube
* 3×3 Classic Cube
* 4×4 Revenge
* 5×5 Professor
* Pyraminx
* Megaminx
* Skewb
* Mirror Cube

### ⚔️ Practice Arena

A dedicated area for practicing cube-solving skills and improving speed.

### 🔥 Daily Challenges

Fresh challenges and scrambles encourage consistent practice and progression.

### 🌍 Community Hub

A community-focused section where cubers can connect, share their experience, and follow the cubing journey.

### 👤 User Dashboard

The application includes an app-style dashboard with sections for:

* Dashboard
* AI Cube Solver
* Learning Center
* Algorithms Library
* Cube Library
* Speed Timer
* Practice Arena
* Daily Challenges
* Community Hub
* Profile
* Settings
